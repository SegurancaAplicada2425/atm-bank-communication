# ATM-Bank Communication Project
This workspace contains a project for implementing secure communication between an ATM client and a Bank server. The project is organized into two main Java modules, built with Gradle.

## Project Structure
- **bank**: Bank server module
- **atm**: ATM client module

## Prerequisites
- Java JDK 11 or higher

## Building the Project

### Building the Bank Server
```bash
git clone https://github.com/SegurancaAplicada2425/atm-bank-communication
cd atm-bank-communication/bank
./gradlew build
```

### Building the ATM Client
```bash
git clone https://github.com/SegurancaAplicada2425/atm-bank-communication
cd atm-bank-communication/atm
./gradlew build
```
